# Pomodoro Infusion

Temporizador Pomodoro con estética de etiqueta de fruta vintage.

- Cuatro planes base con respaldo científico (25/5, 50/10, 52/17 y 90/20).
- Receta propia: eliges cuánto estudiar y el descanso se calcula solo.
- Avisos con sonido, notificaciones del sistema y título de la pestaña.
- Todo se guarda en tu navegador; no hay cuentas ni servidor.

Es un único `index.html` sin dependencias de compilación, publicado con GitHub Pages.
